# Fixture and source provenance

All bundled fixtures are synthetic examples created specifically for this repository. No recorded subject data, medical signals, private serial captures, university documents, API keys, or shared thesis code are included.

The JSON example describes imaginary temperature telemetry. The binary example format was defined for demonstration. Neither is a claim about an existing device's actual protocol.

The reference implementation and documentation were created with AI coding assistance for Ardhya Novri Ramadhan. Test results support the specified software behavior only. External adoption and production reliability are not established by this release.

Expected records are explicit contract oracles. Tests compare them to parser outputs and verify segmentation invariance independently. Bundled fixture input is not generated at test time by the parser under test.
