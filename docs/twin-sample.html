Replay evidence and limits

These are generated Celsius samples, not measurements from a device. Whole-frame drops are known injected events. A sequence anomaly alone does not prove packet loss in a real system. The demonstration uses sum8, not a CRC or an authentication check.

A sample becomes stale 300 ms after its generation time. An older arrival never refreshes a newer displayed value. At the end of replay, the last value remains visible with a stale label.

The existing Python BinaryParser computes every log and timeline in this self-contained file. The browser only selects, projects and replays that data. There are no network requests, sensors, serial ports or external scripts.
